Introduction

What is MLBB Tracker?

A full-stack analytics platform for Mobile Legends: Bang Bang — a Laravel JSON API and a React single-page app, packaged so the whole thing runs on your Windows machine with a single double-click.

The competitive Mobile Legends meta changes weekly, but the numbers live scattered across community sites, spreadsheets and social posts — when they exist at all. MLBB Tracker fetches from two live community providers (Rone Arena API and MLBBDex), merges them against the official hero roster, and serves one cached, attributed picture through a single JSON API.

Every number in the app traces back to a provider observation or a sourced result. Rates are published exactly as the providers report them, sources are named in every response, and when upstream data is missing the interface says so instead of inventing a value. Player accounts use Google sign-in only, your MLBB ID is self-declared and explicitly marked unverified, and no Moonton password is ever involved.

The project ships as a free Windows package (bundled PHP runtime + database, zero installs), as a self-hostable Docker/Render deployment, and as a static demo on GitHub Pages. 60 offline tests keep the API contract and the token verification honest.

Functions

What it can do

Eight things the app does today — each backed by live data or a sourced result.

Live rankings & tier list

All 133 heroes with win, ban and pick rates grouped into S+ → C tiers. Filter by 1–30 day window and Epic → Glory rank bracket; sort any column.

Hero detail & trends

Roles, lanes, live rates and a 7-day win-rate chart — plus “Our Observations”, the app’s own recorded daily history, kept separate from provider trends.

Personal watchlist

Bookmark any hero into the Saved tab: summary strip, average win rate, rank out of 133 and daily movement chips — instantly, on your device.

Head-to-head compare

Put up to three heroes side by side — tier, roles, rates with the best value highlighted, strong/weak matchups — as a shareable URL.

Esports standings

MPL ID / PH / MY / KH standings and the M7 World Championship result — verified against published sources, with honest notes where brackets aren’t published.

Your own dashboard

Consented player connect: a one-time code to your in-game mailbox links your account — real profile, stats, recent matches and top heroes, polled live.

Secure by construction

Google/Firebase sign-in only, ID tokens verified server-side (RS256), Argon2id hashes, SHA-256 session digests, rate limits and a strict CSP.

Installable & portable

Install it as a PWA from the browser, or run the self-contained Windows package — bundled PHP + SQLite, no installers, no admin rights needed.

Google-only accounts

The only credential is a Google sign-in — nothing else exists.
